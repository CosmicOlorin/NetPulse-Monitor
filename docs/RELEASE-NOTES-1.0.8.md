# NetPulse Monitor 1.0.8

Version 1.0.8 adds the Android LAN companion and a clear two-QR setup flow.

- Download the Android APK directly from the desktop PC over the same Wi-Fi/LAN. No external download host is used.
- Pair the installed Android app with a separate persistent QR code.
- View live Internet, router, LTE, signal, quality, outage and unread-SMS telemetry on Android with one-second refresh.
- Pairing secrets are kept in protected platform storage, requests are signed with replay protection, and telemetry payloads are encrypted.
- Pairing remains valid until the user forgets the PC or explicitly revokes all paired phones from the desktop application.
- Mobile access is read-only and restricted to private LAN addresses.
