# NetPulse Monitor 1.0.22

## Dashboard touch-up

- Gives the Current connection, Session since open/reset and Last PC speed test rows enough height so values remain fully visible.
- Places Configure router, Reconnect and Restart router on a full-width action row instead of clipping them at the right edge.
- Keeps the full Show/Hide router or line details label visible and clarifies the PC-to-router plus DNS diagnostic strip.

## Companion dashboard redesign

- Matches the desktop application's dark dashboard structure and visual hierarchy.
- Separates end-to-end phone-to-Internet measurements from TP-Link router LTE telemetry.
- Shows live router upload/download beside band, CID, PCI, EARFCN and RF values.
- Preserves SMS conversations and drafts, LTE controls, connected devices, persistent pairing, notifications and in-app updating.
