# NetPulse Monitor 1.0.11

## Mobile Companion

- Updates now download inside NetPulse with a visible progress bar; the web browser is no longer opened.
- The downloaded APK is verified against its SHA-256 value before Android is asked to install it.
- An optional persistent Android notification shows live connection status outside the app.
- It refreshes every second with router download/upload throughput, current ping, and the ordered LTE band profile, and can be disabled in Companion.
- Desktop SMS contacts are securely synchronized over the paired LAN connection and shown by name in Companion conversations.
